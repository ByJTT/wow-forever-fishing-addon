# Security

This is a small, client-side WoW addon (Lua). It does not collect telemetry, make network requests, or store account credentials.

## Reporting

If you find a security/privacy issue (e.g., accidental personal data exposure, unsafe behavior), please open a **private** report if available on GitHub, or open a minimal public issue **without** sensitive details and ask for a private contact path.

Do not include account names, passwords, tokens, or personal local paths in reports.
